# Contributing

Thanks for helping improve the ZapZap node for n8n.

- **Bugs and ideas:** open an issue with the n8n version, the node version, what you did and what happened. Remove API keys and phone numbers from logs.
- **Pull requests:** keep them small and focused. Run `npm ci`, `npm run lint` and `npm test` before opening one.
- **Templates:** workflows in `templates/` should start with an empty instance and use the Trigger fields (`from`, `text`).
- **Disclosure:** the maintainers work on the ZapZap API. ZapZap connects regular WhatsApp accounts through a channel that WhatsApp does not endorse; keep examples and docs honest about that risk.

By contributing you agree your work is released under the MIT License.
