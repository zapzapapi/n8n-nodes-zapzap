# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email **contato@zapzapapi.com** with the subject "Security: n8n-nodes-zapzap", a description, and steps to reproduce. We aim to reply within 3 business days.

## Scope

This repository is the n8n community node for the ZapZap API (`n8n-nodes-zapzap`). Reports about the node (credential handling, webhook signature verification, request building) are in scope. Issues in the ZapZap service itself can be sent to the same address.

## Supported versions

Only the latest published version on npm receives fixes.
